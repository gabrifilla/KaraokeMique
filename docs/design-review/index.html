B · Festa refinada — mantém Nunito Sans nos títulos, com peso menor e profundidade discreta nos votos. A opção mais próxima da identidade atual.

Preservados: ordem dos blocos, dimensões, cores, textos, ícones, mascote e funções representadas. Os botões dentro das capturas são imagens: não controlam salas reais. Para manter a comparação de posição exata, as caixas e quebras de linha foram congeladas nas capturas; estes estudos ainda não são CSS pronto para aplicar.
