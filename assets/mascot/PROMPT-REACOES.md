# Prompt — expressões do mascote

Ferramenta: `image_gen` integrada, edição a partir de `mascote-microfone-v1.png`, `transparent_background: true`, sem CLI. Uma única folha de sprites 2×2. Resultado preservado em `mascote-reacoes-v1.png` e copiado para o frontend como `mascot-reactions.png`.

```text
Edit/reference target: the attached original Karaoke Míque anthropomorphic microphone mascot. Create ONE production-ready transparent PNG SPRITE SHEET, square canvas, an exact 2 by 2 grid of four full-body character poses. Every quadrant must have the SAME dimensions and consistent framing, with each mascot entirely inside its quadrant, arms and shoes fully visible with generous transparent padding and NO overlap. Preserve the original character identity precisely: silver microphone mesh head, friendly large dark eyes and eyebrows, purple handle/body, neon magenta and cyan accents, white gloves and purple sneakers, polished charming 3D render. Top-left quadrant: CONFUSED, adorable puzzled eyebrow expression, head tilted, palms up shrug, mouth small and questioning; kind and funny, never upset. Top-right: ENCOURAGING, warm gentle smile with one thumbs-up and reassuring leaning pose, cheering someone who was brave enough to sing. Bottom-left: HAPPY GROOVE, pleased grin, eyes joyfully curved, tiny dancing pose with one foot raised, lively but clear silhouette. Bottom-right: BIG CELEBRATION, elated huge smile, both hands raised triumphantly and a few small magenta/cyan sparkles confined to the quadrant, celebrating a great score. Four versions of the same character, same camera, lighting, scale and finish. Transparent background throughout, not white and not checkerboard, no dividers, no labels, no words, no watermark. This is a single 2x2 sprite-sheet asset for the app; positions and separation are critical.
```
